# Support / 支持

- **Bugs and feature requests:** use
  [GitHub Issues](https://github.com/shaloong/mondrian/issues/new/choose).
  English and Chinese are welcome. Include the release/commit and a minimal,
  redistributable reproducer; redact personal paths, tokens, and private media.
- **Suspected vulnerabilities:** follow the [security policy](.github/SECURITY.md)
  and report privately.
- **Community conduct:** follow the [code of conduct](CODE_OF_CONDUCT.md).
- **Development:** start with [setup](docs/dev/setup.md),
  [Windows development](docs/dev/windows-development.md),
  [testing](docs/dev/testing.md), and [contributing](docs/CONTRIBUTING.md).
- **Licensing and private contribution-authority materials:** contact
  contact@shaloong.com; see [LICENSE](LICENSE) and [CLA procedure](docs/legal/CLA-SERVICE.md).

Maintainers should acknowledge bug reports, classify them, and request missing
information even when a fix is not immediately available. Track decisions in
the public issue. GitHub Issues is the public community tracker; the local
`.scratch/` tracker used by engineering agents does not replace it.

Questions can use a normal issue. Discussions is not required for support and
is not currently assumed to be enabled. Support is community-maintained; there
is no general guaranteed response or resolution time.
