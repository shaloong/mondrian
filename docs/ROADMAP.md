## v0.1 — 基础框架（当前）

**目标：** 跑通 媒体加载 → 时间线放置 → 预览 的最小闭环

### Milestone 清单

- [x] Workspace 脚手架（Cargo workspace）
- [x] mondrian-core 类型系统
- [x] mondrian-media：FFmpeg 读取单个视频文件 + 素材导入
- [ ] mondrian-timeline：创建 Timeline，添加 Clip
- [ ] mondrian-renderer：wgpu 渲染单帧
- [ ] mondrian-app：窗口 + 基础 egui 布局

### 验收标准

```text
能打开一个 MP4 文件 → 在时间线上放置 → 用 wgpu 渲染预览第一帧
```

---

## v0.2 — 时间线 MVP

**目标：** 实现可用的剪辑基础操作

### 功能清单

- [ ] 多轨道支持（视频 3 轨 + 音频 3 轨）
- [ ] 拖拽 Clip 到时间线
- [ ] 剪切（Split）、删除、移动
- [ ] 吸附（Snap to Grid / Clip edges）
- [ ] 播放预览（实时解码 → 渲染）
- [ ] 音频波形显示
- [ ] 基础关键帧（位置/缩放/旋转）
- [ ] 撤销/重做（CommandHistory）
- [ ] 项目保存/加载（`.mondrian` JSON 格式）

---

## v0.3 — GPU 渲染引擎

**目标：** 4K 时间线流畅预览，达到专业软件体感

### 功能清单

- [ ] wgpu 多层合成管线
- [ ] YUV → RGB Shader
- [ ] Alpha 混合 / 合成模式（正片叠底、滤色等）
- [ ] 实时关键帧插值（GPU 端）
- [ ] Proxy 代理文件生成（FFmpeg 后台转码）
- [ ] GPU 帧缓存（预渲染队列）
- [ ] 色彩空间管理（Rec.709 / Rec.2020 / sRGB）

---

## v0.4 — AI 工作流引擎

**目标：** 实现面向普通用户的可视化 AI 辅助闭环（点击配置，无需编写 DSL）

### 功能清单

- [ ] 可视化 AI 计划（模板 + 能力卡片 + 参数面板）
- [ ] 模型可选（同能力下多模型切换）
- [ ] 部署方式可选（Cloud API / Local / Hybrid）
- [ ] 字幕转写（faster-whisper + WhisperX）
- [ ] 多语言字幕翻译（支持 SRT 导出 / 双行显示）
- [ ] AI 配音 / 语音克隆（ElevenLabs API 或 IndexTTS）
- [ ] 智能剪辑（去无用镜头&静音、自动粗剪、语义排布）
- [ ] 视频生成能力（文本生成 B-roll、首尾帧延长、自动补镜）

### 最低优先级（短期不实现）

- [ ] 片段自动搜索（任务识别、人物/地点/动作标签、自然语言搜索、自动镜头分类）
