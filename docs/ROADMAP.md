# Mondrian 产品路线图

> 更新日期：2026-04-11
> 说明：本路线图基于当前仓库实现状态修订，目标是先完成可交付的非线编闭环，再扩展高级特效与 AI 能力。

---

## 1. 路线图目标

1. 先做可交付闭环：`导入 -> 编辑 -> 预览 -> 导出 -> 项目恢复`。
2. 先做高频核心能力：时间线精修、导出执行、媒体重连与项目可靠性。
3. AI 与资产生态并行预研，但不阻塞基础剪辑体验。

---

## 2. 当前状态快照（基于代码）

| 能力域 | 当前状态 | 结论 |
| --- | --- | --- |

| 预览与回放 | 已有解码池、缓存、GPU/CPU 合成路径、播放缓冲策略 | 可用，需强化效果接入与稳定性 |
| 项目系统 | 已有项目打包保存/加载、自动保存、崩溃恢复入口、恢复点保留策略 | 可用，需继续强化恢复可观测性 |

| 特效/关键帧 | 数据结构较完整（effect/transition/keyframe），但预览链路接入有限 | 架构在，体验不完整 |
| 音频系统 | 已有基础混音、实时输出、A/V 时钟同步 | 缺波形、包络、效果、响度 |
| 字幕与图形 | 几乎未落地（仅类型或规划） | 后续阶段 |
| 协作与互操作 | 未落地（EDL/AAF/XML、多人协作） | 中后期 |
| 扩展与插件 | 架构愿景存在，实际能力未落地 | 中后期 |

## 4. 近 90 天执行计划（P0/P1）

### P0-1：导出执行链路打通（最高优先级）

**目标：** 从“仅入队”升级为“可真实导出文件”。

- [x] 实现 `RenderQueue` worker（状态流转：Pending -> Rendering -> Encoding -> Completed/Failed）
- [ ] 打通序列逐帧渲染到编码器的执行链（当前为单素材源转码首版）
- [x] 完成 FFmpeg 编码落盘（至少 H.264/AAC MP4）
- [x] 导出进度与失败原因在 UI 可见
- [x] 支持取消任务与队列清理

**验收标准：**

```text
1080p / 60s 时间线可导出有效 MP4；
失败任务可见错误原因；
连续 3 次导出成功率 100%。
```

### P0-2：时间线精修能力补齐

**目标：** 从粗剪可用提升到精修可用。

- [x] 插入/覆盖模式在 UI 可切换并生效
- [x] 片段修剪（Trim In/Out）
- [ ] 滚动/滑移/滑动至少先落地 2 种高频模式
- [x] 片段启用/禁用（不删除）
- [x] 关键编辑操作都进入撤销栈

**验收标准：**

```text
用户可不破坏原素材完成一次完整精修流程；
核心编辑动作均可撤销/重做；
无轨道错位与链接片段破坏。
```

### P0-3：媒体可靠性与项目安全

**目标：** 降低真实项目中的“丢素材/丢进度”风险。

- [x] 源文件离线检测（missing/offline）
- [x] 重新链接（单文件/批量目录）
- [x] 自动保存（间隔可配置）
- [x] 崩溃恢复入口（恢复最近自动保存）

**验收标准：**

```text
移动素材目录后可在 2 分钟内完成重连；
异常退出后可恢复最近自动保存版本。
```

### P1：素材组织与检索增强

- [ ] 文件夹/集合（Bin）
- [ ] 标签与基础元数据检索
- [ ] 素材使用位置反查（被哪些序列/轨道引用）

## 5. 分版本里程碑

### v0.2.1 — 粗剪闭环稳定化（Q2 2026）

**目标：** 让当前已有能力稳定、可连续使用。

- [x] 多轨时间线（视频/音频）
- [x] 拖拽上轨、分割、删除、移动、吸附
- [x] 撤销/重做基础机制
- [x] 项目保存/加载（`.mdp`）
- [ ] 时间线编辑回归测试补齐
- [ ] 播放与预览稳定性收敛（卡顿/超时场景）

### v0.3.0 — 可交付导出（Q3 2026）

**目标：** 具备“做完就能交付”的最低生产能力。

- [ ] 导出执行链路完整落地（剩余：时间线逐帧渲染接入）
- [ ] 预设管理可用（YouTube/TikTok/Proxy）
- [x] 后台队列与取消任务
- [ ] 导出结果校验（帧率、分辨率、时长、音频存在）

### v0.4.0 — 精修与效果可用（Q4 2026）

**目标：** 精细编辑与基础效果真正进入日常可用。

- [x] Trim + 插入/覆盖工作流首版
- [ ] 关键帧编辑 UI（位置/缩放/透明度）
- [ ] 转场与基础滤镜接入实际预览渲染链
- [ ] 混合模式首批可用（Normal/Multiply/Screen）

### v0.5.0 — 字幕与音频增强（Q1 2027）

**目标：** 补全内容制作必需能力。

- [ ] 字幕轨道与样式模板
- [ ] 音频波形显示与波形编辑
- [ ] 音量包络关键帧
- [ ] 基础音频效果（EQ/压缩/降噪至少其一）
- [ ] 响度测量与标准化（首版）

### v0.6.0 — 互操作与扩展（Q2 2027）

**目标：** 与外部专业工具协作。

- [ ] EDL/XML 首版导入导出
- [ ] 插件能力设计冻结（视频/音频/转场）
- [ ] 脚本自动化接口首版

### v1.0.0 — 公测（Q3 2027）

**目标：** 专业用户可稳定完成项目交付。

- [ ] 核心功能稳定
- [ ] 性能目标：4K 25fps 实时预览（参考机型）
- [ ] 崩溃恢复、项目兼容策略、升级迁移策略完善
- [ ] 公测反馈闭环流程

## 6. 暂不优先（明确后置）

- 复杂协作系统（多人并发编辑、片段锁）
- 全量平台一键上传（YouTube/Vimeo 深集成）
- 高阶 AI 工作流产品化（先保留接口与最小实验）

## 7. 技术债务跟踪（更新）

| 模块 | 已知问题 | 优先级 |
| --- | --- | --- |
| export | 缺“时间线逐帧渲染 -> 编码器”完整链路（当前为单素材源转码） | P0 |
| timeline | 精修编辑模式仍缺 roll/slip/slide | P0 |
| assets/media | 缺素材组织（Bin/标签/检索）与重连策略可观测性 | P1 |
| app/project | 自动保存已落地，仍缺恢复冲突处理与策略可视化 | P1 |
| renderer/effects | blend/effects 与预览链路接入不完整 | P1 |
| media/decoder | 硬解后端检测仍有 TODO，跨平台行为需统一 | P1 |
| timeline | 命令历史当前以快照为主，内存占用上限需优化 | P1 |
| audio | 缺波形与效果链 | P1 |
| ai | orchestrator 主要动作仍为 stub | P2 |

## 8. 里程碑退出标准（统一）

每个版本结束前必须满足：

- [ ] 功能完成度达到该版本目标范围
- [ ] 关键路径无 P0 缺陷
- [ ] 至少一轮端到端回归（导入/编辑/预览/保存/导出）
- [ ] 文档与示例同步更新
