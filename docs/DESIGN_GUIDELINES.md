# Mondrian Design Guidelines

> 面向专业剪辑工作流的桌面端视觉与交互规范

## 1. 品牌愿景

Mondrian 的核心气质是：

- 专业，但不冷硬。
- 高密度，但不混乱。
- 有品牌辨识度，但不抢内容风头。

我们把这套方向总结为一句话：

**专业功能的亲和表达。**

这意味着 Mondrian 不是“炫技型 UI”，而是一张让画面、时间线和素材内容自己发声的工作台。

## 2. 当前阶段的设计判断

这份规范以当前 self-hosted winit/wgpu 产品 UI 为准；旧 `egui` 桌面实现只作为迁移参考。

当前主布局采用：

- 顶部：菜单栏与全局命令。
- 左侧：媒体库。
- 中央：程序监视器。
- 底部：时间线。
- 弹窗：导出、新建项目、项目启动、关闭确认。

右侧 Inspector 已进入当前阶段，作为 Effect Controls 的承载区域，默认按“有选择时出现”的方式工作。

## 3. 视觉原则

- 内容优先：画面、轨道内容、素材缩略图优先于容器装饰。
- 深色优先：默认工作区围绕专业暗色模式构建。
- 圆润降压：通过 8px / 12px 圆角降低专业软件的疏离感。
- 控制品牌强度：品牌蓝只用于焦点、主动作、播放头和关键状态。
- 统一语义：颜色、圆角、间距、面板容器必须来自 token，不在组件里散落重复规则。

## 4. 色彩系统

### 4.1 品牌与语义色

- `interaction_highlight`: `#006EFF`
  用于主按钮、焦点、当前选择、关键交互。
- `accent_secondary`: `#0A3565`
  用于更克制的品牌层次，尤其适合时间线视频片段。
- `accent_audio`: `#5AC8FA`
  用于音频语义、轻高亮、覆盖层描边。
- `status_warning`: `#F58220`
  用于警示、风险提示、关键渲染提醒。

### 4.2 深色主题基准

| Token | 值 | 用途 |
| --- | --- | --- |
| `bg_base` | `#121212` | 应用主背景 |
| `bg_surface` | `#1E1E1E` | 主面板背景 |
| `bg_surface_raised` | `#252527` | 次级容器、卡片、工具条 |
| `bg_surface_hover` | `#2B2B30` | Hover / 次级强调 |
| `bg_surface_active` | `#333338` | Active / 选中容器态 |
| `border_subtle` | `#3A3A3C` | 轻分割线 |
| `panel_divider_strong` | `#2F2F33` | 面板边界、窗口轮廓 |
| `text_primary` | `#F2F2F2` | 主文本 |
| `text_muted` | `#767680` | 次级文本 |
| `timeline_clip_video` | `#0A3565` | 视频片段 |
| `timeline_clip_audio` | `#1D587B` | 音频片段 |
| `timeline_playhead` | `#006EFF` | 播放头 |
| `canvas_bg` | `#000000` | Viewer 画布底色 |
| `overlay_fill` | `rgba(18,18,18,0.91)` | 诊断或浮层遮罩 |
| `overlay_stroke` | `rgba(90,200,250,0.63)` | 浮层描边 |

### 4.3 用色纪律

- 蓝色只承担焦点与主路径，不把所有可点击元素都刷成蓝色。
- 音频色是补充语义，不应压过主蓝。
- 警告色只用于需要介入的状态，不作装饰。
- 任何关键状态都不能只靠颜色表达，必须配合文案、位置或图标。

## 5. 圆角与空间体系

Mondrian 采用以 `8px` 为节奏基线的圆角体系：

- `panel_rounding`: `12px`
- `section_rounding`: `8px`
- `card_rounding`: `12px`
- `badge_rounding`: `4px`
- `timeline_clip_radius`: `4px`

空间节奏以 `4 / 8 / 10 / 12 / 16` 为主：

- 面板内部外边距：`12px`
- 区块间距：`10px`
- 默认按钮 padding：`12 x 6`
- Timeline 轨道高度：`42px`
- Timeline 标尺高度：`28px`

## 6. 排版系统

核心工作区不靠巨型标题建立层级，而是依赖清晰的结构、留白与对比。

| 级别 | 当前 token | 用途 |
| --- | --- | --- |
| Panel Title | `16px` | 面板标题 |
| Body | `14px` | 正文、表单、卡片主文本 |
| Label | `12px` | 辅助说明、状态标签 |
| Mono Small | `12px` | 时间码、标尺、技术信息 |
| Mono Large | `24px` | 空画布时间码、大数字 |

字体仍然延续系统字体优先策略，保障中英文混排、路径、素材名和时间码的稳定呈现。

## 7. 组件与区域规范

### 7.1 应用壳层

- 菜单栏和状态栏使用 `bg_surface`，与工作区 `bg_base` 拉开层级。
- 面板容器统一使用 `panel_frame`。
- 弹窗统一使用 `dialog_frame`。

### 7.2 媒体库

- 顶部固定为面板标题 + 导入主按钮。
- 搜索区作为独立 section，不直接裸贴在面板背景上。
- 素材卡片统一使用 raised surface、12px 圆角、轻描边。
- 缩略图优先展示内容，徽标信息仅作辅助。

### 7.3 程序监视器

- Viewer 的重点永远是画布，不让控件压过内容。
- 顶部标题区仅提供当前序列与预览级别信息。
- Transport bar 必须是稳定、紧凑、可盲操作的底部工具条。
- 诊断浮层统一使用 `overlay_fill` / `overlay_stroke`。

### 7.4 时间线

- 时间线是与 Viewer 并列的一级内容区域。
- 播放头使用主蓝色并带圆头，保证在所有轨道里都足够强。
- 视频与音频片段采用不同语义色，但保持统一圆角和描边结构。
- 轨道标签区与轨道内容区必须有稳定层次区分。

### 7.5 导出窗口

- 采用任务卡片流，而不是靠连续 `separator` 堆界面。
- 结构按“预设 / 输入 / 输出 / 提交动作”组织。
- 主动作按钮使用品牌主蓝，次级信息用 muted text。

### 7.6 Effect Controls（右侧属性面板）

- 仅在时间线有片段选择时显示，避免常驻占用工作空间。
- 面板容器复用 `panel_frame`，内部区块复用 `section_frame`。
- 属性行高度与宽度来自 token（如 `inspector_panel_width`、`property_row_height`），避免面板内硬编码。
- 关键帧入口（秒表）要与插值类型组合呈现，不仅依赖颜色传达状态。
- 文案保持克制，优先显示属性与时间信息，不加入与当前操作无关的说明性段落。

### 7.7 项目启动窗口（Start / Bootstrap）

- 启动窗口采用左右非对称结构：左侧品牌叙事卡 + 右侧动作与恢复列表。
- 左侧品牌卡必须使用 `banner.png`，并与 `bg_surface_raised`、`panel_rounding` 组合形成柔和容器。
- 右侧操作区使用 `bg_base` 承载“新建 / 打开 / 退出”动作，主动作使用 `interaction_highlight`，其余动作使用 surface 层级，不加硬边框。
- “开始工作”标题与“新建 / 打开”按钮分两行呈现，按钮行与“最近项目”列表之间需保留明显留白。
- 最近项目条目使用固定卡片宽度（占右侧主要可视宽度），避免条目宽度随文本长度抖动。
- 最近项目卡片宽度应尽量填满右侧内容区，但需保留整体容器右侧 padding，不贴边。
- 最近项目完整文件路径不在列表正文暴露，仅在条目 hover 时显示。
- 最近项目第二行采用元信息格式：`clock` 图标 + “最近编辑时间（多久以前） · 项目大小”。
- 最近项目卡片文字默认不可选中，避免拖动时触发文本选择高亮。
- 崩溃恢复区复用最近项目同款卡片样式（宽度、圆角、不可选中文本与副信息行结构保持一致）。
- 启动列表卡片采用统一垂直节奏：非对称上下内边距（上略大于下）+ 统一元信息图标尺寸，避免出现“上紧下松”的视觉错觉。
- 启动窗口遵守 No-Line 原则：禁止通过 `separator` 或 1px 实线切割区块，靠背景层级与留白建立结构。
- 自动保存恢复区使用列表卡片呈现，优先展示项目名与相对时间（如“12 分钟前”），避免冗余说明文案。
- 启动窗口仅保留一处版本信息（建议放左下角），删除重复版本号与无业务价值口号。

## 8. Token 与实现约束

当前 self-hosted UI 以 `mondrian-ui-theme` semantic tokens 和
`mondrian-ui-widgets` 组件样式为统一基元；旧
`crates/mondrian-app/src/egui_ui/theme.rs` 仅作为 legacy reference。以下容器/结构
语义仍需在自研 UI 中保持对应关系：

- `panel_frame`
- `section_frame`
- `toolbar_frame`
- `dialog_frame`
- `panel_header`

后续新增 UI 时遵循这些规则：

1. 优先新增语义 token，不直接在面板里复制颜色值。
2. 相同容器结构优先复用共享 frame/helper。
3. 时间线、Viewer、媒体库这三块如果出现新的 hover/active/overlay 样式，必须先回到 token 层命名。
4. 品牌色进入主工作区时，必须说明其语义角色，而不是因为“更好看”。

## 9. 当前不强制的内容

以下方向保留为后续阶段，不在当前实现里强推：

- 右侧 Inspector 常驻模式（固定显示）
- 多密度模式切换
- 多主题品牌变体
- 音频波形的完整品牌化渲染体系
- 可自由重排的 workspace 系统

## 10. 一句话总结

Mondrian 当前阶段的 UI 目标是：

**用克制的深色层级、圆润但精确的结构，以及有节制的品牌蓝，把专业剪辑工作区统一成一台可靠、安静、现代的编辑机器。**
