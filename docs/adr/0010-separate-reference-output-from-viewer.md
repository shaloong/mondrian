# Separate Reference Output from Viewer and Export

Mondrian models professional video I/O as one dedicated Reference Output
Module. It consumes the canonical full-raster working composite through a
distinct Program Output role plus the public Audio Program. It is not a Viewer
surface, an Export job, a Monitor Path, or a general platform service.

Renderer alone lowers picture color and physical carrier samples. The
Reference Output Module alone owns exact signal admission, scheduled bundle
ordering, device lifecycle, callback evidence, and the vendor Adapter Seam.
App alone owns machine-local routing and exact author-state binding. Project
author data never stores device identities or active Sessions.

DeckLink COM and AJA NTV2 C++ details remain delayed vendor bridge
Implementations. Missing runtimes and devices fail closed without fake
hardware. The software simulator is valid only for Module contract tests and
can never establish physical-provider or SDI qualification.

This boundary prevents local monitor transforms and diagnostic overlays from
contaminating a clean feed, prevents physical-device state from entering
Undo/Redo, and lets future GPU-resident output deepen one scheduling Module
without duplicating Program Output semantics.
